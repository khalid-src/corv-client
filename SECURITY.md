# Security Policy

## Supported Versions

Security fixes are made against the latest released version of Corv. Users
should update before reporting behavior that may already have been corrected.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting form:

https://github.com/khalid-src/corv-client/security/advisories/new

Include the Corv version, operating system, affected command or component,
reproduction steps, and the potential impact. Remove credentials, private keys,
host addresses, command output, and other sensitive data from the report.

Reports are reviewed privately. Details should remain confidential until a fix
and coordinated disclosure are ready.
